# Contributing to gooseR

We welcome contributions! Please:
- Open an issue to discuss significant changes
- Keep PRs focused and well-documented
- Include examples and tests for complex functions
- Follow tidyverse style guides for R code

## Development
- Install dev deps: `install.packages(c("testthat","knitr","rmarkdown"))`
- Run manual demos in `examples/`
- Use `tests/manual/` for ad-hoc scripts

## Reporting bugs
Please include reproducible examples and session info (`sessionInfo()`).
